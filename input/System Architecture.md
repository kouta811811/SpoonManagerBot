## 2. 設計方針サマリ
AWSサーバーレスアーキテクチャ（Amazon API Gateway + AWS Lambda + Amazon DynamoDB + AWS Systems Manager パラメータストア）を採用し、常時稼働サーバーを排除した完全従量課金・実質無料枠内（$0.00/月）での運用を実現する。  
プラットフォーム開発者利用規約（第5条・第6条・第9条・第10条・第14条）を遵守し、Webhook署名検証（HMAC-SHA256）、APIレート制限制御、およびリスナー個人情報の自動破棄（TTL）をインフラ・基盤レベルで徹底する。

## 4. 方式比較検討

| 比較案 | 構成概要 | メリット | デメリット / リスク | コスト試算 | 総合評価 | 判定 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **案A（採用案）: AWS サーバーレス構成** | API Gateway + Lambda (Python 3.12) + DynamoDB + SSM | 常時起動コスト完全0円、インフラ保守不要、自動スケール、SAM/GitHub Actions連携容易 | コールドスタート（初回数100ms）、実行時間上限15分（Webhook即時応答には影響なし） | 約 $0.00 /月 (AWS無料枠内) | コスト・保守性・安全性のすべてで要件に完全適合 | **◎ 採用** |
| **案B: コンテナ構成 (ECS on Fargate)** | ECS on Fargate + ALB + Aurora Serverless | コールドスタートなし、WebSocket常時接続に強い | 常時起動による固定費（ALB・タスク維持費）、設定・運用の複雑化 | 約 $50〜$120 /月 | 個人開発・イベント駆動Botに対して大幅にオーバースペック | **× 不採用** |
| **案C: 仮想サーバー構成 (EC2 単一インスタンス)** | EC2 (t4g.nano等) + Nginx + SQLite | 自由なOS設定、低スペック時の安価さ | OS/ミドルウェア保守負担大、単一障害点、スケーラビリティ欠如 | 約 $5〜$10 /月 | 障害時の自動復旧工数が大きく運用レス要件を満たさない | **× 不可** |

**【選定理由・決定根拠】**  
配信イベント時のみ実行される特性を活かし、インフラ運用コストを完全0円に抑えるとともに、プラットフォーム規約が求める安全基準（トークン秘匿、過負荷防止）を最もシンプルかつ堅牢に満たせるため「案A」を正式採用。

## 5. 主要コンポーネント詳細仕様

```
[外部配信プラットフォーム]
       │ HTTPS (TLS 1.3) POST /webhook
       ▼
[Amazon API Gateway (HTTP API)]
       │ イベントペイロード受け渡し
       ▼
[AWS Lambda (Python 3.12 / Graviton2)]
       ├── 認証・復号: AWS Systems Manager パラメータストア (SecureString)
       ├── 状態管理・TTL: Amazon DynamoDB (オンデマンド)
       └── 外部API応答: 外部プラットフォーム API (HTTPS / 指数バックオフ)
```

1. **Amazon API Gateway**
   * プロトコル: HTTP API (Payload Format Version 2.0)
   * ルーティング: `POST /webhook`
   * セキュリティ: HTTPS / TLS 1.3
2. **AWS Lambda**
   * ランタイム: Python 3.12 (Architecture: `arm64` / Graviton2)
   * メモリ / タイムアウト: 256MB / 10秒
   * 起動方式: イベント駆動（API Gatewayトリガー）
3. **Amazon DynamoDB**
   * キャパシティモード: オンデマンド（On-Demand Capacity）
   * 機能設定: TTL（Time to Live）属性有効化（`ttl_timestamp`）
4. **AWS Systems Manager (SSM) Parameter Store**
   * 種別: `SecureString` (KMSエイリアス `aws/ssm`)
   * 保管パラメータ: APIトークン、Webhook共有シークレット
5. **CI/CD環境**
   * 実行環境: GitHub Actions
   * 認証方式: AWS IAM OpenID Connect (OIDC) フェデレーション（永久アクセスキー不使用）
   * IaCフレームワーク: AWS Serverless Application Model (AWS SAM)
